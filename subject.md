# TELECOM Graphisme par ordinateur: Projet Personnel

camille.schreck@inria.fr

Deadline : Sunday 15 th February, 2026

Le rendu se fera par mail (camille.schreck@inria.fr). Le sujet du mail devra contenir [PROJET TNCY] . Le projet devra être archivé dans un fichier appelé projet nom prenom zip (ou .tar, .rar) contenant un dossier projet nom prenom avec votre code, rapport et image.

Le projet consiste à créer une scène dans Shadertoy. Le sujet est libre mais le projet devra comporter:
- 1. plusieurs sources de lumière,
- 2. un déplacement de la caméra,
- 3. un disque découpé dans un plan (non aligné avec les axes),
- 4. cylindre,
- 5. un miroir (plan ou sphérique),
- 6. un objet articulé (au moins 2 articulations) (voir figure ci-dessous).
- 7. un effet différent de ce qu'on a fait en cours (objets semi-transparens, matériau spéculaire, toonshading, soft shadow, intersection rayon-cône...)

Le rendu devra comporter:
- 1. le code dans un (ou plusieurs si nécessaire) fichier texte.
- 2. un rapport contenant
- · un lien vers votre shader sur shadertoy
- · une description de la scène et de ce que vous avez fait pour chacun des points ci-dessus (où dans la scène, quelles formes, quels mouvements...)
- · une explication de comment marche le code réalisé pour le point 6
- · les éventuelles difficultés que vous avez rencontrées.
- 3. une image représentative de vos résultats.

Pensez à commenter le code et à écrire du code aussi clair que possible. Les images et schémas sont les bienvenus.
